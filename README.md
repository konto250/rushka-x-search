# X検索式ビルダー

任意の検索語と条件からXの検索式を作成する静的アプリです。検索式のコピー、X検索の起動、ブックマークレットの生成ができます。

## 使い方

1. `index.html` をブラウザで開きます。
2. 検索語を入力します。`猫 OR #猫` のようなXの検索演算子もそのまま使えます。
3. 必要な条件を選びます。検索語を空欄にして条件だけを使うこともできます。
4. 検索式をコピーするか、`Xで開く（最新）` を押します。
5. ブックマークレットを使う場合は、表示されたリンクをブックマークバーへドラッグするか、JavaScriptをコピーしてブックマークのURLへ貼り付けます。

`Xで開く（最新）` を押すと、その時点の検索条件がブラウザのローカルストレージに保存されます。検索式の履歴には新しい順に最大5件を表示し、各項目からX検索を開くか、条件をフォームへ再展開できます。同じ検索式を再度開いた場合は、その条件を先頭へ移します。

## 条件

- メディアのみ: `filter:media`
- フォロー中のユーザーのみ: `filter:follows`
- 引用リツイートを除外: `-filter:quote`
- リツイートを除外: `-filter:retweet`
- リプライを除外: `-filter:replies`
- 指定ユーザーのみ検索: `from:@user` を追加。スペース区切りで複数指定すると `(from:@user1 OR from:@user2)` の形式にします。
- ユーザーを除外: 入力した各ユーザーを `-from:@user` に変換。入力時に `@` を付けても、検索式では一つだけ付けます。
- 日付を指定する: 一つのカレンダー上で開始日から終了日までドラッグして選択します。開始日をクリックし、月を移動して終了日をクリックすることもできます。検索式には `since:YYYY-MM-DD` と `until:YYYY-MM-DD` を追加します。選択した終了日を含めるため、`until:` には翌日を設定します。

「期間をクリア」で日付条件だけを消せます。

終了日が開始日以前の場合は検索・コピーを無効にします。X検索リンクには最新表示用の `f=live` が付きます。ブックマークレットには生成時点の検索式を埋め込みます。条件を変えた後は再登録してください。

ビルドは不要です。`index.html` を直接開くか、任意の静的サーバーで配信してください。

## Vercelへデプロイ

このプロジェクトフォルダで以下を実行します。

```powershell
npx vercel login
npx vercel --prod
```

初回はVercelの案内に従ってプロジェクトを関連付けてください。
